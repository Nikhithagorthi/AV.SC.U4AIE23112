# AffordMed Backend Assessment

This repository contains the solutions developed for the AffordMed Backend Assessment.  
The project is structured into separate modules based on the individual problem statements provided in the assessment.

---

## Repository Structure

### 1. Logging Middleware
Implemented a custom Express middleware for:
- Request logging
- Response status tracking
- API monitoring
- Response time calculation

### 2. Vehicle Maintenance Scheduler
Developed an optimization-based scheduling system to maximize maintenance impact within limited mechanic hours.

#### Features
- REST API implementation
- Dynamic Programming approach
- 0/1 Knapsack optimization
- Modular backend architecture

### 3. Notification Priority System
Built a notification prioritization service based on:
- Notification type weighting
- Recency scoring
- Priority-based sorting
